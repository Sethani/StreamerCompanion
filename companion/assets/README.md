# Companion application icon

The PNG and ICO are the existing Companion project icon, copied unchanged from the personal application's assets during the 1.2.1 extraction follow-up. No personal configuration or other assets accompany them.

`companion-icon.png` supplies the Electron window icon. `companion-icon.ico` supplies the Windows executable icon. Both are explicitly included in the standalone application payload; they are not module assets. The ICO already exists, so the public build does not require an icon-conversion dependency.
