Session

Import and initialize the BRB actions first.

!brb starts; !back stops. Only the broadcaster and moderators can use these commands. Repeating Start does not restart the session.

Keep the existing overlay available on any scene where you want to see the media. This module does not switch scenes or change Overlay Visibility.

Saved mix

Percentages count items selected, regardless of duration. Total must be 100. Zero disables a source; unavailable sources are omitted and their weights redistributed among available sources.

Stop playback before saving. Start uses the saved mix. Self clips use the same saved unused-clip cycle as manual Self Clip Shoutouts.

Followed clips and recovery

Refresh reuses Auto Shoutouts’ followed list and exclusions. It does not send a shoutout or change that list. Up to 20 clips per channel are cached, one channel per timer tick; Stop cancels a refresh. Refresh your own clips in Self Clip Shoutouts.

Unknown requests never retry automatically. Check both players before clearing ownership; clearing sends neither playback nor Stop. A restart stops the rotation and requires an explicit Start. Stop resolves known ownership before sending a guarded Stop; it leaves newer manual media alone.

Phone Deck provides Start, Stop, Toggle and status using this same session. Add cards in its editor; existing cards are preserved.
