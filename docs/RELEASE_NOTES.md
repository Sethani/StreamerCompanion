Experimental module-host release by Sethani, under MIT for first-party code.

This release provides a GitHub module catalogue, explicit dependency-aware installation/updates, SHA-256 verification, private-data preservation and rollback. Update Probe is the recommended first update test; it does not connect to streaming integrations. Video and Spotify are early migration packages with the dependencies documented in their READMEs.

Host self-update and silent installation are not supported. Keep backups, retain the complete Windows application directory and close another Companion instance before launching. Streamer.bot imports remain an explicit user operation. Legacy features not yet migrated remain in the personal integration project.
