# Chat Archive 1.0.0

An optional addition after the required modern switchover. Chat Archive runs on loopback port 3146 with a dock-only history/settings page. It depends on Live Chatbox 1.0.1 and Universal Dock, consumes the existing normalized event feed and opens no Streamer.bot connection. It has no overlay or Phone Deck history contribution and needs no native import or app rebuild.

Capture starts disabled. Enable it explicitly in Archive settings. The module stores original/displayed text and user/member/pronoun data privately in SQLite, deduplicates platform-prefixed message IDs, applies updates without resurrecting deleted records, and excludes Live Chatbox synthetic tests. Moderator deletion removes text by default; retaining deleted text is an explicit option. Persisted moderation tombstones protect against delayed inserts. Search supports literal text, user/member, UTC dates, platform and deletion filters, with 1–500 rows per page. CSV/JSON exports cover all matching rows up to 10,000; CSV neutralizes formula prefixes.

Retention defaults to 30 days, applies on startup, hourly, Save and explicit cleanup. Disabled capture leaves stored history searchable. A stopped/unavailable Live Chatbox does not break history management; reconnect resumes future events. Its feed has no replay, so this cannot reconstruct messages during downtime. No original prototype/database is read or modified, and no private history/settings enter the package. Any historical-data transfer is a separate private migration with backups, not a public legacy-import control.

Configuration uses atomic saves and revision conflicts, exact loopback Host/same-origin checks, CSRF-protected writes and no automatic mutation retries. Health exposes readiness/connection flags, without message/user content. Polling does not replace drafts, focused controls or results. Storage deletion is application-level, not guaranteed erasure from filesystem backups.

Verification: focused runtime tests cover real Live Chatbox normalization/enrichment, synthetic-test exclusion, duplicate/platform IDs, moderation/late updates/tombstones, retention, pagination/literal injection-safe filters, restart, disabled capture, CSV/JSON, failed saves/revision conflicts, rejected Host/Origin/CSRF, feed reconnect and actual package-installed child lifecycle. Hidden Electron checks use disposable profiles and synthetic messages: desktop/mobile layouts, safe text rendering, 120 messages/pagination, empty results, draft/focus/caret preservation and two-client conflicts. All test processes are terminated. Run `npm --prefix companion run check:chat-archive`.

Publication and local adoption evidence will be added after checks and immutable package verification. No existing application needs to be closed for this optional service installation; existing chat/OBS sources stay unchanged.
